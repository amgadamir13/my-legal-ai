# ملف العائلة القانونية

نسخة MVP عربية من منصة لتنظيم ملف عائلي متشعب في مصر، تشمل العقارات والإيجارات والمواريث والمحاضر والقضايا الجنائية.

## ما الذي تغير؟

- استبدال واجهة المحادثة العامة بملف قضية منظم.
- إدخال المحاضر والمحررات يدويًا دون الحاجة إلى رفع ملفات.
- تسجيل الأطراف والصفات ومصادر التحقق.
- إدارة الأصول والعقارات.
- إنشاء خط زمني للقضايا والإجراءات.
- تمييز الادعاءات مثل الفساد أو التلفيق باعتبارها ادعاءات تحتاج دليلاً، لا حقائق تلقائية.
- إنشاء مسودة مراجعة منظمة بالذكاء الاصطناعي عند إعداد `GEMINI_API_KEY`.
- تنزيل نسخة JSON للملف.

## التشغيل

```bash
pip install -r requirements.txt
streamlit run app.py
```

## تنبيه أمني وقانوني

هذه النسخة تحفظ البيانات في جلسة Streamlit الحالية وليست مخزنًا دائمًا أو نظامًا آمنًا للإنتاج. قبل إدخال بيانات شخصية أو قضايا حساسة يجب إضافة تسجيل دخول، تشفير، تخزين آمن، صلاحيات، نسخ احتياطي، وسياسة احتفاظ وحذف. لا يصدر التطبيق رأيًا قانونيًا نهائيًا ولا يغني عن مراجعة محامٍ مصري مختص.

## المرحلة التالية

- قاعدة بيانات دائمة مشفرة.
- دخول وصلاحيات للمالك والمراجعين.
- استيراد ملفات PDF بعد اختبار الخصوصية.
- ربط كل نتيجة بمحرر أو مصدر.
- سجل تدقيق غير قابل للمحو.
- وحدة منفصلة للقضايا الجنائية ذات صلاحيات أشد.
