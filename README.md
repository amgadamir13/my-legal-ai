# منصة ملف العائلة القانونية

نسخة عربية لإدارة ملف عائلي متشعب في مصر، تشمل العقارات والإيجارات والتركات والمواريث والمحاضر والقضايا الجنائية.

## الجديد في هذه المرحلة

- إضافة تخزين SQLite محلي دائم بدل الاعتماد على جلسة Streamlit وحدها.
- حفظ ملف القضية تلقائياً عند كل تشغيل/تحديث.
- جدول `cases` لحفظ الملف كاملاً بصيغة JSON مع بياناته الأساسية.
- جدول `audit_log` مبدئي لسجل العمليات.
- استمرار واجهة الفروع، المحاضر، الأطراف، الأصول، الخط الزمني، المهام، والمراجعة.

## التشغيل

```bash
pip install -r requirements.txt
streamlit run app.py
```

ينشئ التطبيق ملف `family_legal_case.sqlite3` محلياً. هذا مناسب للتجربة المحلية فقط، وليس جاهزاً بعد لاستضافة بيانات قانونية حساسة.

## تحذير أمني

قبل الاستخدام الحقيقي يجب إضافة تسجيل دخول، تشفير، صلاحيات، نسخ احتياطي آمن، سياسة احتفاظ وحذف، وحماية لملف قاعدة البيانات. لا ترفع ملف SQLite أو الأسرار إلى مستودع عام.
