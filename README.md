# منصة ملف العائلة القانونية — حساب خاص بمالك واحد

## الدخول الخاص

التطبيق الآن مخصص لمستخدم واحد فقط. لا توجد حسابات عائلية أو مستخدمون إضافيون.

في إعدادات Streamlit Secrets أضف:

```toml
APP_USERNAME = "اسم-المستخدم"
APP_PASSWORD = "كلمة-مرور-قوية-وفريدة"
GEMINI_API_KEY = "مفتاحك-إن-أردت-التحليل-الآلي"
```

لا تضع هذه القيم في الكود أو GitHub. يمكن استخدام `APP_PASSWORD_SHA256` بدلاً من `APP_PASSWORD` إذا أردت عدم حفظ كلمة المرور نفسها في Secrets.

## ملاحظات التخزين

- التطبيق يحفظ الملف في SQLite على بيئة التشغيل.
- زر «نسخة احتياطية JSON» ينشئ نسخة قابلة للتنزيل.
- في الاستضافات السحابية قد تضيع الملفات المحلية عند إعادة التشغيل؛ يلزم لاحقًا ربط قاعدة بيانات دائمة ومشفرة.
- JSON غير مشفر؛ لا تحفظه أو ترسله عبر قناة غير آمنة.

## التشغيل المحلي

```bash
pip install -r requirements.txt
streamlit run app.py
```

هذه الأداة للتنظيم والتحليل الأولي وليست بديلاً عن محامٍ مصري أو جهة التحقيق.
