# منصة ملف العائلة القانونية

نسخة عربية أولية لإدارة ملف عائلي متشعب في مصر، تشمل العقارات والإيجارات والتركات والمواريث والمحاضر والقضايا الجنائية.

## ما تم تنفيذه

- لوحة ملف رئيسي للوارث أو صاحب الأصول.
- تقسيم القضية إلى فروع مستقلة، مثل الطعن على عقد القسمة أو فرع الإيجار أو الفرع الجنائي.
- إدخال المحاضر والقضايا والإنذارات والأحكام والعقود يدويًا.
- تسجيل الأطراف وصفاتهم ومصدر إثبات الصفة.
- تسجيل الأصول والعقارات.
- إنشاء خط زمني.
- إنشاء مهام ومواعيد ومسؤولين وأولويات.
- أسئلة تحقق قبل إصدار أي رأي.
- سجل تدقيق للنشاط داخل الجلسة.
- تصدير JSON.
- مراجعة آلية اختيارية مع فصل الوقائع عن الادعاءات.

## التشغيل

```bash
pip install -r requirements.txt
streamlit run app.py
```

## ملاحظات مهمة

هذه النسخة لا تثبت وجود فساد أو مؤامرة أو تلفيق، ولا تقدم رأيًا قانونيًا نهائيًا. كل ذلك يسجل كادعاء يحتاج إلى مستند ومراجعة محامٍ مصري. كما أن البيانات الحالية محفوظة في جلسة Streamlit فقط وليست تخزينًا دائمًا أو نظامًا آمنًا للإنتاج.

قبل إدخال بيانات شخصية أو جنائية حقيقية، يجب إضافة:

- تسجيل دخول قوي.
- تشفير أثناء النقل والتخزين.
- قاعدة بيانات دائمة وآمنة.
- صلاحيات حسب الدور.
- سجل تدقيق غير قابل للمحو.
- نسخ احتياطي وسياسة احتفاظ وحذف.
- مراجعة قانونية وأمنية.

المرحلة التالية المقترحة: تحويل نموذج الجلسة إلى قاعدة بيانات آمنة، ثم إضافة إدارة المستخدمين والمستندات بعد اختبار الخصوصية.
